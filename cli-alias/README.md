# @openlabor/cli — deprecated

The CLI is published as [`openlabor`](https://www.npmjs.com/package/openlabor).

```bash
npm install -g openlabor
npx openlabor list roles
```

This package is a thin alias kept so that anything pinned to the old scoped name keeps
working. It contains no logic — it forwards every command to `openlabor`, so the two
behave identically.

Documentation: https://github.com/OpenLabor/openlabor
